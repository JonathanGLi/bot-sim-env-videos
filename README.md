# BoT_Sim environment videos

**Watch them here (they play in the browser): https://jonathangli.github.io/bot-sim-env-videos/**

Init and goal stability videos for the BoT_Sim environment PRs, in Isaac Lab and the MuJoCo mirrors, three seeds each. The files under `videos/` are named `<env>_<isaac|mujoco>_<init|goal>_seed<k>.mp4`. GitHub's file viewer does not play mp4; open a clip at `https://jonathangli.github.io/bot-sim-env-videos/videos/<name>.mp4` instead.
